Data Analytics project on  Unveiling the Android App Market: Analyzing Google Play Store Data dataset including data cleaning, merging, visualization, and sentiment analysis to extract meaningful insights.

# 📊 Data Analytics Task – Google Play Store Analysis

## 📌 Project Overview

This project focuses on performing data analytics on the Google Play Store dataset. It includes data cleaning, preprocessing, merging multiple datasets, and extracting insights using visualization and sentiment analysis.

---

## 📂 Datasets Used

* **apps.csv** – Contains app details like category, rating, installs, price, etc.
* **user_reviews.csv** – Contains user reviews and sentiment (Positive, Negative, Neutral)

---

## ⚙️ Key Steps Performed

### 🔹 Data Cleaning

* Removed invalid and missing values
* Converted columns (Installs, Price, Size) into numeric format
* Handled inconsistent data (e.g., “Varies with device”)

### 🔹 Data Merging

* Merged datasets using the common column **App**
* Created a unified dataset for analysis

### 🔹 Exploratory Data Analysis (EDA)

* Category-wise app distribution
* Rating distribution analysis
* Installs vs Rating relationship

### 🔹 Sentiment Analysis

* Analyzed user sentiments (Positive, Negative, Neutral)
* Visualized sentiment distribution using charts

### 🔹 Data Visualization

* Bar charts, scatter plots, box plots, heatmaps
* Insights into app popularity and performance

---

## 📊 Key Insights

* Identified most popular app categories
* Observed relationship between installs and ratings
* Majority of apps are free
* User sentiment trends across apps

---

## 🛠️ Technologies Used

* Python 🐍

* Matplotlib

## 🚀 Conclusion

This project demonstrates how raw data can be transformed into meaningful insights using data analytics techniques. It covers the complete pipeline from data cleaning to visualization and interpretation.
